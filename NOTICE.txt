Сторонние данные
================
Файл src/data/vindata.ts содержит таблицы из библиотеки vininfo 1.11.0 (https://github.com/idlesign/vininfo):
  - словарь WMI (производители),
  - диапазоны стран по ISO 3780,
  - таблицы деталей для Lada (AvtoVAZ), Nissan, Opel, Renault и Ford Australia.
Данные переведены на русский и адаптированы под JavaScript; в названии модели Renault исправлена опечатка «Megan II».
Лицензия vininfo (BSD-3-Clause) приведена в файле LICENSE-vininfo.txt и должна сопровождать распространение.

Таблицы Chrysler (1968–1980) составлены по материалу MoTales (David Zatz), Mercedes-Benz по MB Spares,
Porsche по 911UK. Остальные справочники (Ford, GM, заводы, JDM) составлены по памяти и могут содержать неточности.

universal-vin-decoder, Java-версия (MIT, © 2019 Sergiu Drahnea; текст лицензии в LICENSE-uvd-java.txt)
-------------------------------------------------------------------------------------
Использованы: десять WMI, которых нет в vininfo (3H3, KRT, KRV, MB2, MC3, NA6, X7M, X89, XU7, Y6L), и таблицы линий модели
и заводов Hyundai. В самом проекте эти таблицы взяты из руководства youcanic.com/guide/hyundai-vin-decoder
и содержат следы машинного перевода, поэтому названия приведены к нормальному виду, а значения помечены как предположительные.
Остальная часть проекта (Java-приложение, таблицы двигателей Hyundai) не использована: двигатели в нём нигде не подключены к декодеру.

universal-vin-decoder, TypeScript-версия (MIT, © 2024 Mobito SRL; текст лицензии в LICENSE-uvd-ts.txt)
-------------------------------------------------------------------------------------------------------
Использованы дополнительные диапазоны стран (Эфиопия, Руанда, Эсватини, Уганда, Россия E*). Словарь WMI из этого проекта
использовался до 11.11.2026, теперь он собирается прямо из Википедии (см. ниже). Правило определения года из этого проекта не использовано.

Википедия, «Vehicle identification number» (файл src/data/wmi-wiki.ts)
----------------------------------------------------------------------
Словарь WMI (1534 записи) собран скриптом tools/build_wmi_wiki.py из раздела «List of common WMI» статьи английской Википедии,
ревизия 1384921858 от 10.11.2026 (https://en.wikipedia.org/w/index.php?oldid=1384921858); текст статьи сохранён
в tools/sources/wikipedia-vin-1384921858.json. Текст Википедии распространяется по лицензии CC BY-SA 4.0, авторы — участники Википедии
(история правок: https://en.wikipedia.org/w/index.php?title=Vehicle_identification_number&action=history).
Названия производителей оставлены на английском, как в источнике; если у кода несколько строк, они объединены через «; »;
мелкосерийные производители записаны шестью символами (WMI и символы 12–14 VIN).

Mitchell 1, «2009 VIN Decoding» (файл src/data/legacy-us.ts)
----------------------------------------------------
Все данные Mitchell 1 (этот и следующие разделы с пометкой Mitchell 1) собраны в отдельный пакет src/mitchell.ts.
Обычная сборка (npm run build) их не включает; со справочником собирает npm run build:mitchell. Решение о включении
принимается отдельно для каждого способа распространения (расширение, сайт, библиотека).
Из PDF-справочника Mitchell 1 взяты только значения кодов для американских автомобилей 1974–1980 годов:
серии, кузова и двигатели GM (Chevrolet, Pontiac, Oldsmobile, Buick, Cadillac), серии и двигатели Ford/Mercury/Lincoln,
коробки, серии, кузова, модели и двигатели AMC. Документ целиком в расширение не включён.
Справочник защищён авторским правом издателя. Если расширение будет распространяться за пределами личного использования,
уточните условия использования этих таблиц у правообладателя. Для Cadillac 1976 в исходном тексте таблица двигателей не читается, код показывается без расшифровки.

Mitchell 1, номера двигателей и Mazda 1979–1980 (файл src/data/mitchell-engines.ts)
-------------------------------------------------------------------------------
Из справочника Mitchell 1 взяты только значения кодов: стартовые номера двигателей Porsche 1973–1999 (стр. G-129…G-130),
начальные символы номеров двигателей Volkswagen 1974–2002 (G-190), коды двигателей Volkswagen 2003–2009 (G-187…G-189),
диапазоны номеров двигателей Beetle 1973–1980 (G-184), типы двигателей Mercedes-Benz 2004–2009 (таблицы Model Reference),
номера шасси Mazda 1979–1980 и диапазоны серийных номеров (G-87, G-94). Собрано скриптом tools/build_mitchell_engines.py
из PDF справочника (сам PDF в проект не входит). Часть отдельного пакета src/mitchell.ts.

Mitchell 1, европейские и азиатские марки (файл src/data/euro-tables.ts)
-----------------------------------------------------------------
Из того же справочника взяты значения кодов: тип шасси Mercedes-Benz (1973–2004, 143 типа), код типа Audi (позиции 7–8, 1980–2003, 15 кодов),
диапазоны порядковых номеров Volvo (1973–1997, около 140 диапазонов) и кузов Hyundai (6-й символ, 2000–2008).
Условия использования те же, что и для src/data/legacy-us.ts: переносились только значения, документ целиком не включён.

Wikibooks, «Vehicle Identification Numbers (VIN codes)» (файлы src/data/wmi-wb.ts и src/data/plants-wb.ts)
------------------------------------------------------------------------------------------
Источник: выгрузка страниц книги https://en.wikibooks.org/wiki/Vehicle_Identification_Numbers_(VIN_codes), лицензия CC BY-SA.
src/data/wmi-wb.ts: 840 кодов производителей, которых нет в vininfo и в словаре WMI из Википедии (в основном новые российские, китайские и европейские).
src/data/plants-wb.ts: коды заводов (11-й символ) для VW, Audi, Mercedes-Benz, Porsche, Saab, Volvo, Peugeot, Hyundai, Kia, Isuzu, Daewoo, Daihatsu,
Land Rover, Jaguar, Honda, Nissan, Mazda, Mitsubishi, Toyota, Ford, GM, Chrysler. Названия оставлены на английском.
Условие CC BY-SA (указание авторства и распространение производных данных на тех же условиях) нужно учитывать при публикации расширения.

Volvo (файл src/data/volvo-wb.ts): модельный ряд (4-й символ до 2009 года, 7-й с 2010 года) и коды двигателей из книги Wikibooks (CC BY-SA, американский рынок).

Kia (файл src/data/kia-wb.ts): линия модели (4–5-й символы до 2009 года, 4-й с 2010 года) и двигатель (8-й символ) из книги Wikibooks (CC BY-SA, американский рынок).

VW и Audi, модельная линия 7–8-го символов (файл src/data/vwaudi-wb.ts): из книги Wikibooks (CC BY-SA, американский рынок). Используется, когда в справочнике Mitchell 1 кода нет (2003–2009 и с 2010 года).

Mercedes-Benz (файл src/data/mb-wb.ts): 586 записей «модель и двигатель» для американского рынка 2002+ по символам 4–7 из книги Wikibooks (CC BY-SA).

Peugeot, европейский формат (функция peugeotDetails в src/decode.ts): модельная линия по 4-му символу из книги Wikibooks (CC BY-SA).
Исходные тексты использованных страниц книги с номерами ревизий: tools/sources/wikibooks-vin-2026-11-11.json.

Заводы GM, Ford и Chrysler для старых американских номеров (файл src/data/plants-us-wb.ts): таблицы заводов из книги Wikibooks (CC BY-SA 4.0),
страницы «GM/VIN Code History» (ревизия 4610767), «Ford/VIN Codes» (4664675) и «Chrysler/VIN Codes» (4649803). Собраны скриптом
tools/build_plants_us.py; тексты страниц сохранены в tools/sources/wikibooks-vin-us-2026-11-11.json. У GM завод выбирается по годам его работы,
у Ford и Chrysler таблица служит для проверки старых кодов 1965–1980 (подтверждённые коды помечаются в подсказке).

Японская Википедия, коды кузова японских моделей (файл src/data/jdm-wiki.ts)
---------------------------------------------------------------------------
Коды кузова (型式) и годы продаж из карточек «Infobox 自動車のスペック表» в 1291 статье категорий «トヨタの車種», «日産の車種»,
«ホンダの車種», «マツダの車種», «スバルの車種», «三菱の車種», «スズキの車種», «ダイハツの車種», «レクサスの車種» и их подкатегорий
японской Википедии (https://ja.wikipedia.org), данные на 12.11.2026. Текст Википедии распространяется по лицензии CC BY-SA 4.0,
авторы — участники Википедии. Названия моделей — по межъязыковым ссылкам на английскую Википедию. Собрано скриптом
tools/build_jdm_wiki.py; извлечённые поля карточек с номерами ревизий статей сохранены в tools/sources/jawiki-models-2026-11-12.json.

Русская Википедия, заводы бывшего СССР (файл src/data/ussr.ts)
--------------------------------------------------------------
Коды WMI предприятий бывшего СССР (разделы «WMI заводов бывшего СССР» и «WMI мелких заводов бывшего СССР» статьи
«Идентификационный номер транспортного средства», ревизия 152804777), индексы моделей по названиям статей о моделях
(«ВАЗ-21099», «ГАЗ-3302», …) и их перенаправлениям, значения второй цифры индекса по статье «Системы индексации автотранспорта
в СССР и России» (ревизия 152717760). Источник — русская Википедия (https://ru.wikipedia.org), данные на 12.11.2026, CC BY-SA 4.0,
авторы — участники Википедии. Английские названия — по межъязыковым ссылкам на английскую Википедию, иначе транслитерация.
Собрано скриптом tools/build_ussr.py; выгрузка лежит в tools/sources/ruwiki-vin-ussr-2026-11-12.json.
То, что 4–9-й символы VIN у ВАЗ — индекс модели с модификацией, взято из заводского руководства по эксплуатации
(раздел «Идентификационные номера автомобиля», пример XTA211440…); перенесён только этот факт.

tpocr.com, коды VIN американских машин 1965–1975 (файл src/data/legacy-tp.ts)
-----------------------------------------------------------------------------
Значения кодов взяты из таблиц сайта https://www.tpocr.com (данные на 12.11.2026): кузов (3–4-й символы) и двигатель (5-й символ)
в 11-символьных номерах Ford и Mercury/Lincoln 1965–1975 годов; серия, кузов и двигатель (с 1972 года) в 13-символьных номерах
Chevrolet, Pontiac, Oldsmobile, Buick и Cadillac 1965–1975 годов; модели в 8-символьных номерах Cadillac 1965–1970 годов;
завод, коробка, серия, кузов, модель и двигатель в 13-символьных номерах American Motors 1966–1975 годов; модельный ряд,
серия, кузов и двигатель в 13-символьных номерах Plymouth, Dodge и Chrysler/Imperial 1966–1975 годов (опечатки источника:
двигатель «237» у Plymouth 1969 года прочитан как 273, класс «0» — как буква O). Перенесены только соответствия «код → модель, кузов,
двигатель», приведённые к сокращениям декодера; текст страниц не переносился. Собрано скриптом tools/build_tpocr.py; выгрузка
таблиц лежит в tools/sources/tpocr-vin-2026-11-12.json. Две явные опечатки источника (V8 240 и V8 350 у Ford) отброшены в
пользу записи с соседней страницы; где таблицы Ford и Mercury расходятся, показываются оба варианта.

NHTSA vPIC (папка public/nhtsa/ и файл src/nhtsa.ts)
------------------------------------------
Папка public/nhtsa/ — компактная копия базы NHTSA vPIC (выпуск «lite» 2026-10, vPICList_lite_2026_10, версия 4.10 от 17.10.2026):
индекс кодов производителей (WMI), справочники и шаблоны VDS по всем публичным элементам (модель, кузов, двигатель, КПП, завод, оснащение,
прицепы, автобусы, мотоциклы, батарея), формульные шаблоны, таблицы Vehicle Specs (оснащение по марке, модели и году),
значения по умолчанию по типу ТС и список исключений контрольной цифры.
Данные Национальной администрации безопасности дорожного движения США (NHTSA) относятся к общественному достоянию.
Алгоритм сопоставления (src/nhtsa.ts) повторяет хранимую процедуру spVinDecode из дампа базы. Сеть нужна только для необязательного запроса отзывных кампаний.
Скрипт сборки данных лежит в tools/build_nhtsa.py. Файл tests/fixtures/vpic-api.json — ответы API vPIC (DecodeVin) для 16 номеров,
снятые 11.11.2026 для сверки офлайн-декодера.

Фото автомобилей (файл src/carimage.ts)
------------------------------------
Картинки в расширение не вложены: при расшифровке по марке, модели и году запрашивается заглавное фото статьи Wikipedia
(REST API page/summary), а авторство и лицензия берутся из Wikimedia Commons (imageinfo, extmetadata). Принимаются только файлы Commons
с указанной свободной лицензией; под каждым фото показаны автор, лицензия и ссылки на страницу файла и статью.
В запросах участвуют только марка, модель и год, сам VIN наружу не передаётся. Отключить фото можно флажком под полем ввода.

Префиксы сертификации японских номеров кузова (файлы src/jdm-cert.ts и src/data/jdm-cert.ts)
---------------------------------------------------------------------------------------------
Значения кодов взяты из таблиц Министерства земли, инфраструктуры, транспорта и туризма Японии (国土交通省)
«自動車排出ガス規制の識別記号»: таблица для норм с 2005 года (по состоянию на 10.01.2025) и таблица для норм до 2004 года,
https://www.mlit.go.jp/jidosha/jidosha_tk10_000001.html. Перенесены только значения кодов в собственной структуре,
описания переведены и сокращены. Условия повторного использования материалов сайта МЛИТ перед публикацией стоит проверить.
